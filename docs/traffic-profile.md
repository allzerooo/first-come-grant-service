# 트래픽 프로파일

## 프로덕션 가정치

| 항목 | 수치 | 근거 |
|------|------|------|
| Claim RPS (피크) | 30,000 | 토스 라이브쇼핑 분당 수십만 요청 참고 |
| View RPS (피크) | 60,000 | Claim의 2배 (조회 > 쓰기 패턴) |
| 동시 접속 | 100,000 | - |
| 일일 총 요청 | 10억 | 쿠팡 billions/day 사례 참고 |

## 부하 시나리오

| 시나리오 | RPS | 지속 시간 | 목적 |
|----------|-----|-----------|------|
| Smoke | 10 | 1분 | 기본 동작 확인 |
| Load | 목표 RPS | 5분 | 정상 부하 검증 |
| Stress | 목표 RPS × 2 | 5분 | 한계점 확인 |
| Soak | 목표 RPS | 30분 | 메모리 누수, 커넥션 풀 확인 |

## 트래픽 패턴

- **Burst**: 선착순 이벤트 시작 시 순간 폭증 (0 → 피크 in 1초)
- **Steady**: 일반 운영 시간대 일정 부하
- **Off-peak**: 새벽 시간대 낮은 부하
